# Fitlog - Exercise & Fitness Planner

## 📌 Project Description

**Fitlog** is a modern fitness and exercise planning web application built with Next.js. Users can explore different exercises, view detailed exercise information, and add exercises to their personal daily workout plan.

The project focuses on providing a clean, responsive, and user-friendly interface for managing fitness activities.

## 🚀 Technologies Used

* **Next.js 16**
* **React**
* **JavaScript**
* **Tailwind CSS**
* **daisyUI**
* **Next.js App Router**
* **Context API**
* **REST API**
* **Next.js Dynamic Routes**
* **Vercel**

## ✨ Key Features

### 1. 🏋️ Exercise Listing

Users can browse different exercises and fitness activities from the Fitlog application.

### 2. 📋 Exercise Details

Each exercise has a dynamic details page where users can view complete information about the selected exercise.

### 3. ➕ Add to Today's Plan

Users can click **"Add to today's plan"** to add an exercise to their personal workout plan.

### 4. 💾 Save Exercises

Users can save exercises for later so they can easily access their preferred workouts.

### 5. 📱 Responsive Modern UI

The application provides a modern, responsive interface that works across desktop, tablet, and mobile screen sizes.

## 🛠️ Run Locally

Clone the repository and install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open:

```text
http://localhost:3000
```

## 📦 Production Build

Create a production build:

```bash
npm run build
```

Run the production server:

```bash
npm start
```
